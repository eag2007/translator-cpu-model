# Документация по синтаксису Lisp и команда ассемблера

## Язык Lisp

Язык основан на S-выражениях. Каждая конструкция записывается в круглых скобках, где первым элементом является оператор или имя функции, далее следуют аргументы.

### 1. Переменные и арифметика

```lisp
(set x 10)
(set y (+ 2 3))
```

Поддерживаемые арифметические операции:

| Оператор | Описание |
|---|---|
| `+` | Сложение |
| `-` | Вычитание |
| `*` | Умножение |
| `/` | Деление |
| `%` | Остаток от деления |

### 2. Операции сравнения

| Оператор | Описание |
|---|---|
| `>` | Больше |
| `<` | Меньше |
| `>=` | Больше или равно |
| `<=` | Меньше или равно |
| `==` | Равно |
| `!=` | Не равно |

### 3. Условный оператор

```lisp
(if (> x 10)
    (
        (print_string "big")
    )
    (else
        (
            (print_string "small")
        )
    )
)
```

Блок `else` необязателен.

### 4. Циклы

`while` — выполнение блока, пока условие истинно.

```lisp
(while (> x 0)
    (
        (print_number x)
        (set x (- x 1))
    )
)
```

`repeat` — выполнение блока заданное количество раз.

```lisp
(repeat 3
    (
        (print_string "hello")
    )
)
```

### 5. Функции

Объявление функции осуществляется через `defunc`, вызов — через `funcall`.

```lisp
(defunc add (a b)
    (
        (+ a b)
    )
)

(funcall add (10 20))
```

### 6. Ввод и вывод

| Конструкция | Описание |
|---|---|
| `(input)` | Ввод числа |
| `(input [N])` | Ввод строки заданного размера |
| `(print_number X)` | Вывод числа |
| `(print_string X)` | Вывод строки |
| `(print_char X)` | Вывод символа |

Пример:

```lisp
(set x (input))
(print_number x)
(print_string "hello")
(print_char 65)
```

### 7. Массивы

| Конструкция | Описание |
|---|---|
| `(array N)` | Создание массива из N элементов |
| `(aget address index)` | Получение элемента массива |
| `(aset address index value)` | Запись элемента массива |

Пример:

```lisp
(set arr (array 10))
(aset arr 0 100)
(print_number (aget arr 0))
```

### 8. Строки

| Конструкция | Описание |
|---|---|
| `"text"` | Строковый литерал |
| `(string N)` | Выделение памяти под строку |
| `(getchar address index)` | Получение символа по индексу |
| `(setchar address index value)` | Изменение символа по индексу |

Пример:

```lisp
(set text "hello")
(set buffer (string 32))

(setchar buffer 0 65)
(print_char (getchar buffer 0))
```

### 9. Пример программы

```lisp
(set x 5)

(defunc add (a b)
    (
        (+ a b)
    )
)

(set result (funcall add (x 10)))

(if (> result 10)
    (
        (print_string "result: ")
        (print_number result)
    )
)

(repeat 3
    (
        (print_string "hello")
    )
)
```

## Язык ассемблера

Все команды поддреживаемые ассемблером

### 1. Инструкции работы с памятью

| Мнемоника         | Описание                                    |
| ----------------- | ------------------------------------------- |
| `LOAD X`          | Загрузить `MEM[X]` в ACC                    |
| `LOADI N`         | Загрузить непосредственное значение N в ACC |
| `LOAD_ADDR label` | Загрузить адрес метки в ACC                 |
| `LOAD_IND X`      | Загрузить `MEM[MEM[X]]` в ACC               |
| `LOAD_SP N`       | Загрузить `MEM[SP + N]` в ACC               |
| `STORE X`         | Записать ACC в `MEM[X]`                     |
| `STORE_IND X`     | Записать ACC в `MEM[MEM[X]]`                |
| `STORE_SP N`      | Записать ACC в `MEM[SP + N]`                |

### 2. Арифметические инструкции

| Мнемоника | Описание                         |
| --------- | -------------------------------- |
| `ADD X`   | ACC = ACC + MEM[X]               |
| `ADDI N`  | ACC = ACC + N                    |
| `SUB X`   | ACC = ACC - MEM[X]               |
| `SUBI N`  | ACC = ACC - N                    |
| `MUL X`   | ACC = ACC \* MEM[X]              |
| `MULI N`  | ACC = ACC \* N                   |
| `DIV X`   | ACC = ACC / MEM[X]               |
| `DIVI N`  | ACC = ACC / N                    |
| `MOD X`   | ACC = ACC % MEM[X]               |
| `MODI N`  | ACC = ACC % N                    |
| `CMP X`   | Установить флаги по ACC - MEM[X] |
| `CMPI N`  | Установить флаги по ACC - N      |

### 3. Управление потоком выполнения

| Мнемоника    | Описание              |
| ------------ | --------------------- |
| `JUMP label` | Безусловный переход   |
| `BEQ label`  | Переход при Z = 1     |
| `BGE label`  | Переход при N = V     |
| `CALL label` | Вызов функции         |
| `RET`        | Возврат из функции    |
| `IRET`       | Возврат из прерывания |
| `HALT`       | Остановка процессора  |

### 4. Работа со стеком

| Мнемоника | Описание                        |
| --------- | ------------------------------- |
| `PUSH`    | Поместить ACC в стек            |
| `POP`     | Извлечь значение из стека в ACC |
